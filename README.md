# LiveKit Backchannel Lab

Blue Machines SDE-1 assignment: an independent, cancellable backchannel engine with paired audio replays, measurable response latency, and a live microphone demo.

## Build status

Implementation in progress. The assignment PDF has been reviewed. This repository began empty; no existing work was replaced. No benchmark results or live deployment are claimed yet.

## Planned milestones

1. Engine and behavioural concurrency tests: cancellation, cooldown, end-of-turn suppression and normal-response priority.
2. Eight repeatable audio scenarios and paired benchmark instrumentation.
3. LiveKit integration using public APIs, comparison UI, event timelines and microphone mode.
4. Validation, measured results and operational documentation.

The Recruitbot reference project is being reviewed locally for reusable architectural ideas. Its source, credentials and customer data will not be copied into this repository.
